- Modules now hold items by amount instead of by slot. Each module holds 27 stacks' worth of items in any mix, so you can keep adding new kinds of items until that room is used up (for example 1,728 stone, or one each of 1,728 different items).
- Unstackable items like tools still take a whole stack of room each.
- The percentage bar shows how much of that room is used.
- Capacity upgrades add 4 or 9 stacks of room to every module.
- Existing worlds convert automatically; no items are lost.

Requires Fabric Loader 0.20.1+ and Fabric API. Install on both the client and the server.
