- Settings now pop out on the left of the menu, the same size and place as the crafting panel. The settings button opens and closes it, and opening it closes the crafting panel (and the other way around).
- New Tab and Edit Tab open the tab editor right under the settings panel, like the recipe book under the crafting grid. The rest of the menu keeps working while it's open.
- Left-clicking a tab while holding an item now adds that item to the tab (right-click still works).
- The help (?) tooltip is updated: it now covers shift-clicking items, the sort button and turning the disguise.

Requires Fabric Loader 0.20.1+ and Fabric API. Install on both the client and the server.
