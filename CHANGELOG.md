- Right-click a tab while holding an item to add that item to the tab. Left-click only selects a tab.
- Tabs can no longer be dragged to a new position.
- Shift-clicking an item in the storage now always moves a full stack into your inventory.
- The percentage bar now counts used slots, so it shows 100% when no empty slot is left.

Requires Fabric Loader 0.20.1+ and Fabric API. Install on both the client and the server.
